# PlayWit Creations resource pack

The optional resource pack for the PlayWit Creations Minecraft server. It gives the server's magic creatures
(the Shardling, Ember Wisp, Abyss Jelly, Mossback, the nine Nemesis bosses, Server, the companion, and the
Stormcaster's Tempest Cloud) real
3D models. Players who skip it still see the
creatures, in their block look.

- **The pack:** download it from [Releases](../../releases). The server offers it when you join.
- **`models/`:** the changed models (Blockbench `.bbmodel`), as the pack is built from them.
- **`CREDITS.txt` and `licenses/`:** where each model comes from, what was changed, and its license.

All 15 models are credited one by one in `CREDITS.txt`: 4 (the Shardling, Ember Wisp, Abyss Jelly and Mossback) are
other people's openly licensed work (MIT and EUPL-1.2), changed for the server; the 11 others (the nine Nemeses,
Server and the Tempest Cloud) are original and MIT licensed (LICENSE). Each model stays under its own license (in `licenses/`);
`LICENSE` covers only this repo's own files.
