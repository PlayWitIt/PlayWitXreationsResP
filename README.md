# PlayWit Creations resource pack

The optional resource pack for the PlayWit Creations Minecraft server. It gives some of the server's creatures
(the Shardling, Ember Wisp, Abyss Jelly and Mossback) real 3D models. Players who skip it still see the
creatures, in their block look.

- **The pack:** download it from [Releases](../../releases). The server offers it when you join.
- **`models/`:** the changed models (Blockbench `.bbmodel`), as the pack is built from them.
- **`CREDITS.txt` and `licenses/`:** where each model comes from, what was changed, and its license.

The models are other people's openly licensed work (MIT and EUPL-1.2), changed for the server; see
`CREDITS.txt`. Each model stays under its own license (in `licenses/`); `LICENSE` covers only this repo's own files.
